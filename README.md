# 01～39 號碼機率分析 App

Android Studio / Kotlin / Jetpack Compose 原型。

## 第一版功能
- 內建 32 期測試資料（第一筆視為最新一期）
- 01～39 完整模型評分排名
- 近期 5 / 10 期統計、總出現次數、遺漏期數
- TOP 20 五號候選組合
- 新增最新一期後即時重新分析

## 開啟方式
1. 使用 Android Studio 開啟此資料夾。
2. 等待 Gradle Sync 完成。
3. 用 Android 模擬器或實機執行 app。

## 說明
模型評分只是依歷史資料建立的統計指標，不代表隨機事件的真實未來機率。
